# Go packages whose PROD code uses concurrency primitives (sync.{Mutex,RWMutex,
# Once,WaitGroup,Map,Pool,Cond,Locker}, channels, `go func`, named-goroutine
# launches, atomic.{Add,Store,Load,Swap,CompareAnd,Bool,Int,Uint,Pointer}).
# These packages run `go test -short -race`; everything else runs without
# `-race` to halve test-binary build + run time.
#
# Nightly cross-platform-nightly.yml still runs `go test -short -race ./...`
# across the whole tree on ubuntu / macos to catch any race that slipped past
# this hand-curated list (e.g. a test-only race in a package whose prod code
# is single-threaded but whose tests fan out goroutines).
#
# Regenerate via scripts/regen-go-shards.sh (see docs/engineer/pointers.md).
