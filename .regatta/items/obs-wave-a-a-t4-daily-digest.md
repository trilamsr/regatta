## Task

New CLI subcommand `cmd/regatta/digest.go` — `regatta digest --date YYYY-MM-DD` reads the previous 24h of metrics + logs + PR-merge events and writes `docs/digests/YYYY-MM-DD.md` with the seven sections per spec §6.2:

1. Loop health (tick p95, gate counts, alarms fired).
2. PRs landed (title, A+ tier, cost USD, dispatch→merge time).
3. Adversarial findings (count by fate).
4. Substrate health (events/sec, chain breaks, divergence count).
5. Cost (USD by DAG, cumulative week).
6. Triggers (days remaining to each unlock).
7. Followups filed (count + link to tracking issues).

Per amendment §5 L8 — prepend a YAML front-matter block with named fields so the digest is lock-step parseable alongside the markdown body. Schema: `date`, `tick_p95_ms`, `prs_landed_count`, `cost_usd_today`, `cost_usd_week`, `chain_breaks`, `divergence_count`, `alarms_fired`, `triggers` (map).

Data sources: Prom HTTP API when `OTEL_EXPORTER_OTLP_ENDPOINT` is set (or `OTEL_METRICS_PROMETHEUS_PORT`); fall back to sqlite reads from `event_token_spend` and substrate event tables when Prom is unreachable. Banner in the digest output when the fallback kicks in (spec §9 R5 + decision-priority UX > velocity).

**First-digest degraded contract (amendment §4 — verbatim required strings):**

- PRs-landed section, before C-T2 ships: print exactly `PRs landed — emitter ships C-T2 (Wave C); see #<issue>`.
- Adversarial-findings section, before D-T1 ships: print exactly `Adversarial findings — emitter ships D-T1 (Wave D); see #<issue>`.
- Removal owners pinned: C-T2 implementer removes the PRs-landed placeholder as part of its PR; D-T1 implementer removes the Adversarial placeholder. Cite both in A-T4's PR body.

**Zero-PR-day handling (spec §9 R6):** when PR count = 0 on a day where the PRs-landed emitter exists, prepend the digest with `Loop quiet (Phase-S relaxation hold? CI-block? operator vacation?)`. Skip the empty PR section. No silent zeros.

Cron: `scripts/cron/daily-digest.sh` runs daily at 09:00 local time. The script invokes `regatta digest --date $(date -u -d yesterday +%F)` and commits the file via the standard PR workflow with `[DOCS]` prefix.

**Determinism (per A+4 rubric):** same inputs produce byte-equal markdown. Sort all collections; format USD with fixed precision; tabulate durations in a canonical form. Tests assert determinism via golden-file fixtures.

First digest lands at `docs/digests/2026-06-03.md` — generated by `regatta digest --date 2026-06-03` against the local sqlite fixture.
